# Third-Party Notices

## opencode

This repository is a behavioral port to Rust of [opencode](https://github.com/anomalyco/opencode), pinned at reference tag **v1.18.13** (released 2026-08-04).

What is ported from the upstream specification:
- **Behavior**: streaming chat, tool calling, permission gating, session persistence, configuration loading
- **Tool prompt texts**: descriptions in `crates/ganja-tool/src/` derive from upstream `packages/opencode/src/tool/*.txt` and from prompt strings embedded in the tool sources under `packages/opencode/src/tool/` (MIT licensed, attributed below)
- **Theme definitions**: color schemes and styling adapted from `packages/tui/src/theme/`. The files under `crates/ganja-tui/assets/themes/` — `opencode.json`, `tokyonight.json`, `gruvbox.json`, `aura.json` — are verbatim copies of the upstream `packages/tui/src/theme/assets/` files of the same names.
- **System prompt texts**: the files under `crates/ganja-core/src/prompt/` are verbatim copies of upstream files — `anthropic.txt`, `gpt.txt`, `default.txt`, `plan.txt` and `build-switch.txt` from `packages/opencode/src/session/prompt/`, `explore.txt` from `packages/opencode/src/agent/prompt/`, and `initialize.txt` from `packages/opencode/src/command/template/initialize.txt`. `crates/ganja-tool/src/{task,websearch,skill,question}.txt` are likewise verbatim copies, of `packages/opencode/src/tool/{task,websearch,skill,question}.txt`; they sit beside the tools they describe, which is where upstream keeps them. `crates/ganja-tool/src/plan_exit.txt` is a verbatim-with-one-adaptation copy of upstream `packages/opencode/src/tool/plan-exit.txt`: its plan-file clause says the complete plan has been presented, because ganja keeps the plan as transcript prose rather than a file. The `QUESTION`, `HEADER`, `YES_LABEL`, `YES_DESCRIPTION`, `NO_LABEL`, `NO_DESCRIPTION`, `TITLE` and `OUTPUT` constants in `crates/ganja-tool/src/plan.rs` derive from upstream `packages/opencode/src/tool/plan.ts`. `websearch.txt` is copied verbatim and its `{{year}}` token substituted at runtime, which is what upstream does with the same file. The `Instructions from: {path}` header and the `<env>` block wording derive from `packages/opencode/src/session/{instruction.ts,system.ts}`. The `build`, `plan`, `general` and `explore` agent descriptions in `crates/ganja-core/src/agent.rs` are verbatim from `packages/opencode/src/agent/agent.ts`, and the permission-denial message in `crates/ganja-core/src/session.rs` derives from `packages/core/src/v1/permission.ts`.

- **UI strings and data tables**: the question dialog's `Type your own answer` row label derives from `packages/tui/src/routes/session/question.tsx`; the effort picker's wording from `packages/tui/src/component/dialog-variant.tsx`; the composer's newline chord defaults (`shift+enter,ctrl+enter,alt+enter,ctrl+j`) from `packages/tui/src/config/keybind.ts`; the attachment mime table from `packages/tui/src/component/prompt/local-attachment.ts`; and the prompt-history file shape from `packages/tui/src/prompt/history.tsx`.

The implementation is original Rust code using idiomatic patterns; it is **not a code translation** but rather a faithful behavioral port of the upstream TypeScript/JavaScript specification.

**Cursor wire (in progress):** the cursor provider's protobuf messages are defined in ganja's own `crates/ganja-provider/src/provider/cursor.proto`, authored primarily against wire facts observed during a live spike; where those facts are silent, individual field numbers and names derive from the plugin's generated descriptor (`src/proto/agent_pb.ts` at `a37a6ba9a6d6d8d176bb68248f59240271f46767`), attributed field-by-field at the site — never copied wholesale. The Rust for those messages is generated by [`buffa`](https://github.com/anthropics/buffa) (Anthropic's pure-Rust Protocol Buffers implementation, Apache-2.0, a Cargo dependency resolved through `Cargo.lock` like any other) via the `buf.build/anthropics/buffa` remote plugin, and checked in under `crates/ganja-provider/src/provider/cursor/`. Where the cursor request/response semantics derive from the [opencode-cursor](https://github.com/ephraimduncan/opencode-cursor) plugin (MIT, per its `package.json` declaration), that derivation is attributed at the site with the source pinned; the credential-flow endpoint facts already used by `crates/ganja-provider/src/auth/cursor.rs` are interop facts (URLs, parameters, status semantics), not copied expression.

## Scope of this file

These notices cover material **incorporated into this repository's own sources**: ported behavior, prompt texts, and theme definitions.

Rust dependencies are not vendored here — they are resolved by Cargo and recorded in `Cargo.lock`. Their license notices are therefore not reproduced in this file; a complete, generated attribution list belongs with the distributed binaries and is produced at packaging time (e.g. `cargo about`). Listing individual crates here would give an arbitrary and misleading picture of a tree that carries hundreds of them.
